================================================================================
                         DATA FLOW - SUMMARY
================================================================================

┌─────────────────────────────────────────────────────────────────┐
│ 1. Page Load (SSR)                                              │
│    ├─ getConcertsPageData() called in controller                │
│    ├─ Fetches: upcoming + past concerts                         │
│    ├─ Enriches with: personnel + extras + programs             │
│    └─ Groups past by year: concertsByYear                      │
│                                                                 │
│ 2. Template Rendering (concerts.ejs)                            │
│    ├─ Renders year pills from yearsList                         │
│    ├─ Renders year panels with concert cards                   │
│    ├─ Embeds hidden concert-full-details for each              │
│    └─ Includes 2 empty modal shells:                           │
│        - #concert_lightbox (for individual details)             │
│        - (no pre-rendered #year_modal, JS creates it)          │
│                                                                 │
│ 3. JavaScript Initialization                                    │
│    ├─ concerts-year-toggle.js:                                 │
│    │  ├─ Finds .year-pill buttons                              │
│    │  ├─ Attaches click listeners                              │
│    │  └─ buildOverlay() ready to create modal on demand        │
│    ├─ concerts-lightbox.js:                                    │
│    │  ├─ Finds #concert_lightbox                               │
│    │  ├─ Attaches close button listener                        │
│    │  └─ Waits for openConcertFromDOM() calls                 │
│    └─ concerts.js (glue):                                       │
│       ├─ Binds details label toggles                           │
│       ├─ Intercepts summary clicks                             │
│       └─ Delegates to openConcertFromDOM()                    │
│                                                                 │
│ 4. User Interaction                                             │
│    ├─ Click year pill                                          │
│    │  └─> buildOverlay() + openYear(year)                      │
│    │      └─> Modal appears with that year's concerts          │
│    ├─ Click concert card in modal                              │
│    │  └─> openConcertFromDOM(concertId)                        │
│    │      ├─ Find details_<ID> in DOM                          │
│    │      ├─ Copy to #concert_poster_container                 │
│    │      └─> Lightbox appears over year modal (z-index stacking)
│    └─ ESC or click backdrop                                     │
│        └─> closeConcertLightbox() / closeModal()               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
